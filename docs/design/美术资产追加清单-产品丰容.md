# 美术资产追加清单（产品丰容 v1）

> 给美术同学：现有 6 张宠物图已验收、不用重画；本次只追加 2 个必须项 + 3 个可选项。

## 1. 项目与风格

「芽芽」是 Windows 桌面陪伴宠物：一盆会随学习状态变化的植物（健康 / 蔫 / 长草 / 开花）。
风格与现有 6 张一致：干净、圆润、低饱和、无描边文字；透明背景，放在桌面不抢眼。

现有资产（已验收，**不要覆盖**）：

| 文件 | 用途 |
|---|---|
| `pet_healthy.png` | 健康待机 |
| `pet_blink.png` | 眨眼帧 |
| `pet_wilt_a.png` / `pet_wilt_b.png` | 开始蔫 / 彻底蔫 |
| `pet_weeds.png` | 逃避后长草 |
| `pet_bloom.png` | 开花彩蛋（3 秒） |

## 2. 追加清单

### 必须（2 项）

| 文件 | 用途 | 规格 |
|---|---|---|
| `pet_sleep.png` | 夜间形态（23:00–7:00）、"今天到这里"收尾 | 1024×1024 RGBA 透明 PNG，与现有图同画布、同盆底锚点 |
| `app.ico` + `tray.ico` | exe / 窗口 / 托盘图标清晰度 | 多尺寸 ICO：16 / 24 / 32 / 48 / 64 / 128 / 256，透明背景 |

### 可选（3 项，有则更好）

| 文件 | 用途 | 规格 |
|---|---|---|
| `pet_water.png` | 番茄休息相位（浇水/喝水），替代现在的"只摇摆" | 同 1024×1024、同锚点 |
| `empty_*.png` ×3 | 空状态：无记录 / 无历史 / 宠物已隐藏 | 400×300，透明或浅底，**图内无文字** |
| `week_card_bg.png` | "我的这一周"图片卡背景 | 1080×1350，中间留安全区（上下各 15%） |

> 不需要：加载动画序列帧、多语言文字图、摄像头/麦克风相关图形、深色专用宠物图（透明图可直接用）。

## 3. 通用规格（沿用第一批）

- **画布**：1024×1024，PNG-24 + Alpha，sRGB；
- **锚点**：盆底中心 = 画布底边中点，位置 **y ≈ 769 / 1024（75.1%）**；所有姿态的盆底必须对齐，
  与 `pet_healthy.png` 叠图误差 ≤ 2 像素；
- **轮廓位置**：角色在画面中的大小/位置与现有 6 张一致，切换不跳动；
- **禁止**：图内文字、水印、投影超出画布、纯白底、渐变遮罩压暗（夜间变暗由程序做）；
- **体积**：单张 ≤ 600KB（现有约 340KB）；
- **命名**：全小写 + 下划线，严格按上表；放 `src/Yaya.App/Assets/pet/`；
- **源文件**：同时交 PSD/AI/Procreate 源文件（分层，便于改色）。

## 4. 逐项要求

### 4.1 `pet_sleep.png`（睡姿）

- 与 `pet_blink.png` 区分：blink 是"瞬间闭眼"，sleep 是**整体放松**——叶片/花头略下垂、盆身不动；
- 眼睛闭合（向下弯的弧线即可），不要口水/气泡/文字"Zzz"；
- 颜色比 healthy 略暗半档（程序还会再叠一层透明度），但不要变成灰色；
- 200×200 显示时能一眼看出"睡着了"。

### 4.2 图标（`app.ico` / `tray.ico`）

- 图形建议：现有花盆 + 一片叶子/一朵小花的剪影，或宠物头部剪影；
- 16px 下仍可辨认（不要细线、不要小字）；32px 下轮廓清楚；
- 绿色主色与现有 `#2F6B3F` / `#7CB342` 同系；
- 透明背景，圆形/圆角方形底均可，但要留 10% 安全边；
- 一个 ICO 内含 7 个尺寸；`app.ico` 与 `tray.ico` 可以是同一套（托盘可更简）。

### 4.3 `pet_water.png`（可选）

- 休息相位的"浇水/喝水"姿态：小水壶或水滴，动作轻微，不出现文字；
- 盆底锚点不变；与 healthy 叠图不跳。

### 4.4 空状态（可选）

- 3 张：`empty_no_record.png`、`empty_no_history.png`、`empty_hidden.png`；
- 400×300，透明或极浅底，画面元素不超过 60%，给 UI 文字留位置；
- 不要文字。

### 4.5 周卡背景（可选）

- 1080×1350（4:5），浅色纸感或淡绿渐变；
- 中间 70% 为安全区（文字/数字压在上面），四边留白；
- 不要文字、不要日历格线（格子由程序画）。

## 5. 交付与验收

1. 打包 `art-v2-日期.zip`，内含 PNG/ICO + 源文件 + 一张 200×200 的预览图；
2. 放到 `art-review/v2/` 或直接发组长；**不要直接覆盖现有 6 张**；
3. 组长按下面清单验收后，再复制进 `src/Yaya.App/Assets/pet/`：

- [ ] 尺寸/格式/透明通道正确，无白边、无黑边光晕；
- [ ] 与 `pet_healthy.png` 叠图，盆底对齐误差 ≤2px；
- [ ] 200×200 下姿态可辨（睡得着 / 浇得动）；
- [ ] 图标 16px、32px 下可辨；ICO 含 7 个尺寸；
- [ ] 单张 ≤600KB，命名完全一致；
- [ ] 图内无文字、无水印。

## 6. 优先级与时间

- **先做**：`pet_sleep.png` + 图标（这两项直接决定"夜间形态"和"不像学生作业"）；
- **有空再做**：`pet_water.png` → 空状态 → 周卡背景；
- 不设硬 deadline；开发侧已有降级（睡姿=变暗+闭眼、图标=现有 32px、空态=文字、周卡=纯色）。
