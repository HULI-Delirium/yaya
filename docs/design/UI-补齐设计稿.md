# UI 补齐设计稿（P0 · 2026-10-29 审查通过）

> 结论先说：**领域逻辑与数据链路做完了，但 UI 只到"能跑通"，没到"能给人用"。**
> 本稿覆盖 P0 缺口；**2026-10-29 已审查通过，P0 全部实施**（后续 L1–L4 见《产品丰满度路线图》）。
> 依据：当前代码（`App.xaml.cs`、`PetWindow`、`MainWindow`、`ReportWindow`、`WeeklyReportWindow`）
> 与 SRS V0.3（FR-01/03/04/07/08/10）。

## 0. 一句话

现在能演示"宠物随状态变 + 每日三句话 + 本周 7 节点树"；但**番茄只能从复盘窗的「明天开始」启动、没有任何停止入口**，
**点桌宠没有反应**，**看不到跨天历史**，**首次启动没有引导**，**宠物不能隐藏**。

## 1. 现状盘点（代码事实，不是猜测）

| 界面 / 入口 | 现在有什么 | 缺什么 |
|---|---|---|
| 启动 | 宠物窗 + 托盘；当日首次自动弹复盘；设置窗只在托盘里 | 首次运行引导；可发现的入口 |
| 桌宠 | 拖动（左键 DragMove）；游离气泡（两个按钮）；动画/姿态 | 点击或右键菜单；隐藏；番茄状态 |
| 托盘菜单 | 暂停采集 / 设置 / 今日复盘 / 本周报告 / 一键清空 / 退出 | 开始/停止番茄；显示/隐藏宠物 |
| 设置窗 | 采集、提醒、穿透、专注/休息分钟、导出、清空、LLM | 频次上限、免打扰时段、宠物显隐、状态解释 |
| 今日复盘 | 三句话 + 「明天开始」 | — |
| 本周报告 | 7 节点树（开花/花苞/灰）+ 3 行数字 + 建议 | 每日分钟数；跨周 |
| 历史 | **无**（`GetAllDailySummaries` 只用于导出） | 近 N 天列表/趋势 |
| 番茄 | 仅 `ReportWindow` 的「明天开始」调用 `StartFocus`；`Stop()` **零调用方** | 启动/停止/剩余时间 |

对应 SRS：

- **FR-01**（开始/结束番茄）：**不满足**——没有普通启动入口，也无法停止；
- **FR-03** 验收（当前状态 + 最近一次迁移原因）：**不满足**——设置页只有一行 `StatusText`；
- **FR-04**（每日 ≤3 次、免打扰时段）：**不满足**（原计划的展示门控，尚未开始）；
- **FR-07**（首次启动数据用途说明页）：**不满足**——只有设置里的按钮；
- **FR-08**（宠物显隐）：**不满足**；
- **FR-10**（本周报告）：**部分满足**——有周树与总量，无每日分钟。

> 另：`干净机器8步验证checklist.md` 第 5 步写"托盘/设置启动一个番茄"，**当前版本做不到**；
> 该项在 P0 落地前必然失败，执行人要提前知道。

## 2. P0 目标（路演前必须做到）

1. 用户能自己**开始、停止**一个番茄，并看到剩余时间；
2. **点桌宠有菜单**，不用记托盘；
3. 能看到**近 14 天每天专注多少**（不是只有今天和本周树）；
4. 第一次打开知道**这是什么、采什么、不采什么**；
5. 能**隐藏/恢复宠物**；
6. 补上**每日 ≤3 次 + 免打扰时段**（M 级需求，与门控合并）。

P1（不在本轮）：暂停番茄、完整"最近事件"列表、跨周对比图、趋势交互。

---

## 3. 交互设计

### 3.1 启动

- **首次运行**（`settings.HasCompletedOnboarding == false`）：显示 `WelcomeWindow`（数据用途 + 三条红线 +
  「开始第一次专注」/「先逛逛」），写标记后不再弹。
- **非首次**：静默启动（宠物 + 托盘），**不弹主窗口**——这是低打扰红线的一部分。
- 当日首次仍自动弹复盘（现状保留）。
- **不新增"主窗口"**，避免又开一个要关的窗；入口靠桌宠菜单 + 托盘。

### 3.2 桌宠菜单

- 手势：左键按下后移动 ≤4px 且 ≤300ms → 视为点击，弹出菜单；移动超过阈值 → 拖动（保持现状）。
- 右键：同一菜单。
- 菜单项（动态）：

```
┌──────────────────┐
│ 开始专注 25 分钟  │  ← 番茄进行中变为「停止专注 12:34」
│ ─────────────── │
│ 今日复盘…        │
│ 本周报告…        │
│ 历史记录…        │
│ 设置…            │
│ 隐藏宠物          │
│ ─────────────── │
│ 退出             │
└──────────────────┘
```

- 鼠标穿透开启时：不响应点击/右键，设置页与托盘提示"穿透模式下菜单不可用"。

### 3.3 番茄状态

- 宠物上方加一条 200×22 状态条：`专注 24:31` / `休息 04:12`；无番茄时隐藏（透明）。
- 托盘 tooltip 同步；菜单项按相位切换；完成/中断仍走托盘气泡。
- 开始番茄后立刻写入相位（Core R6 生效），停止写 `PomodoroAborted`（现有 `Stop()` 已做）。

### 3.4 历史窗口（新）

- 480×460，非模态，可最小化；标题「专注记录」。
- 内容：**近 14 天**，每天一行：

```
10-29 周三  ████████████  72 分   纠正 1 次   "晚上 19:30 是今天最强的一段。"
10-28 周二  ████           25 分   纠正 0 次   "今天先做了最难的 12 分钟。"
10-27 周一  —               无记录
```

- 顶部汇总：本周合计 / 日均 / 最长连续专注天数。
- 数据来源优先级：`daily_summary` 缓存 → 无缓存但有 events 的日期用现有 `DailyReportAggregator` 现算 →
  无数据留空；**只读，不新增表、不改 Core**。
- 空态：「还没有记录，开始一个番茄吧」+ 一个「开始专注」按钮。

### 3.5 首次启动说明页

- 复用现有 `DataUsageText`（采集边界/不采什么/数据在哪/一键清空/LLM 默认关闭）。
- 底部两个按钮：「开始第一次专注」（启动 25 分钟番茄 + 关窗）、「先逛逛」（关窗）。
- 写 `settings.HasCompletedOnboarding = true`；设置页仍保留「数据用途说明」可再看。

### 3.6 宠物显隐

- 桌宠菜单 + 托盘各一项「隐藏宠物 / 显示宠物」；隐藏时托盘 tooltip 提示；进程不退出。

### 3.7 每日上限 + 免打扰（与门控合并）

- App 层计数：当日已展示的 nudge 次数（**持久化到 settings**，重启不重置，按本地日期切换）。
- 免打扰时段默认 23:00–7:00，可配（设置页两个时间输入）。
- 只过滤**展示**，不改 Core 冷却与判定（Core 不动）。

## 6. 验收清单（人工）

1. 冷启动 → 只出现宠物与托盘，**不弹主窗口**；当日首次弹复盘（现状保留）；
2. 首次运行弹欢迎窗，关闭后不再弹；设置里仍能再看说明；
3. 点桌宠弹菜单；拖动 4px 以上不弹菜单；
4. 菜单「开始专注」→ 状态条出现倒计时；「停止专注」→ 写 `PomodoroAborted`、状态条消失；
5. 番茄结束 → 托盘气泡 + `PomodoroFocusCompleted` 事件；
6. 历史窗显示近 14 天；数字与导出 JSON 的 `daily_summary` 一致；无记录日显示空态；
7. 隐藏宠物 → 宠物消失、托盘可恢复；穿透开启时菜单不可用且可解释；
8. 免打扰时段内不弹气泡；当日第 4 次起不弹；重启后计数不重置；
9. 8 步 checklist 第 5 步改为"桌宠/托盘菜单启动番茄"，可执行；
10. `dotnet build` 0 警告 0 错误 + `dotnet test` 88/88 仍绿（Core 未动，测试不应变化）。

## 8. 待你拍板（带推荐）

1. **要不要新增"主窗口/首页"？** 推荐**不加**：首次给欢迎窗，之后静默，入口放桌宠菜单与托盘（符合低打扰）。
2. **历史范围**：推荐**近 14 天 + 本周汇总**，不做全量分页（课程演示够用，性能稳）。
3. **番茄状态展示**：推荐**宠物上方状态条**（直观，路演镜头里看得见），托盘 tooltip 兜底。
4. **桌宠菜单触发**：推荐**左键单击 + 右键同菜单**，用 4px 阈值区分拖动；不做双击（双击与拖动更容易冲突）。
5. **免打扰计数持久化**：推荐**写 settings**（重启不重置），按本地日期归零。
6. **顺序**：推荐先做番茄控制与桌宠菜单（路演最显眼），再做历史窗；不建议先做设置项。

## 9. 不做 / 顺延

- 番茄「暂停」（Core 与服务都没有，属于新需求，顺延 v0.2）；
- "最近事件列表"完整版（FR-03 验收先以"当前状态 + 最近一次迁移原因"满足，见 SRS V0.3）；
- 跨周对比、图表交互、导出图片；
- 账号、云同步、多端（红线外）。

## 10. 风险

- 10 天窗口内 3.25 天 UI + 0.5 天门控 + 验证/路演，**没有余量再扩需求**；
- 宠物窗透明 + 常驻动画，新增状态条后需复测 CPU（基线 0.56%，红线 ≤1%）；
- 历史窗"现算"只在无缓存日发生，14 天上限，避免卡顿；
- 单击与拖动的阈值需要真机手感调，建议 4px/300ms 起步。
